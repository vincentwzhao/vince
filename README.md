# Vincent Zhao — Portfolio

A responsive, static portfolio highlighting projects, technical skills, and education.

## GitHub Pages

The repository includes an Actions workflow for GitHub Pages. If Pages is not enabled yet, open **Settings → Pages**, select **GitHub Actions** as the build and deployment source, then rerun the workflow from the Actions tab. Once deployed, the site URL is:

https://vincentwzhao.github.io/vince/

## Local preview

Open index.html in a browser.
